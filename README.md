## What I've Learned Through Real-World Development

### Backend & API Design
- Designing and maintaining REST APIs with Node.js, Express, and MongoDB.
- Building endpoints for test discovery, exam attempts, reattempts, results, report cards, flashcards, attendance, and doubt sessions.
- Keeping business rules consistent across endpoints, including test visibility and eligibility.
- Working with database models and validation to support application workflows.

### Reliable Application Workflows
- Implementing answer persistence, autosave, timed submissions, and recovery after page reloads or connection interruptions.
- Using periodic and navigation-triggered saves, optimistic UI updates, and deadline handling.
- Handling edge cases around scoring, marking, date and timezone logic, and production bugs.
- Rendering user-provided question content more safely with DOMPurify and loading MathJax when needed.

### AI-Powered Features
- Integrating Google Gemini to generate report cards, study suggestions, and personalized recommendations.
- Adding retry handling and fallback responses to make AI-dependent features more resilient.
- Using AI capabilities as part of practical product workflows rather than as standalone demos.

### Reports, Analytics & File Delivery
- Generating PDF reports with PDFKit and programmatically rendered performance charts.
- Storing generated files in AWS S3 and delivering them through CloudFront.
- Reusing cached reports to avoid unnecessary regeneration.
- Building analytics around accuracy versus speed, topic-level weaknesses, section timing, streaks, and badges.

### Frontend Engineering
- Building application interfaces with React, SvelteKit, Svelte, and Tailwind CSS.
- Translating designs into reusable components and integrating frontends with backend APIs.
- Improving assessment experiences with optimistic answer selection, lazy-loaded math rendering, and responsive save flows.
- Using state management tools such as Redux and Zustand where appropriate.

### Cloud, Deployment & Production Support
- Deploying frontend and backend services using Firebase Hosting, Docker, and Google Cloud Run.
- Working with AWS S3 and CloudFront for report storage and delivery.
- Troubleshooting production issues and improving frontend build and delivery performance.
- Integrating external services and handling webhooks, including Zoom and notification workflows.

### Product & Platform Features
- Developing learning features such as flashcards, spaced-repetition categories, deck resumption, and saved questions.
- Building administrative workflows for scheduling, teacher rotation, timetable conflict prevention, and worksheet assignment.
- Considering permissions, role-based views, and timezone-aware behavior when implementing features.
